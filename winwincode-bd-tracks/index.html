04 · P1 MODEL DYNASTY

Fusion · Adaptive Intelligence Runtime

Fusion 不是「Planner=A / Coder=B / Verifier=C」的 Multi-Agent 分角色。定义是：同一问题、同一 Canonical Context，多模型 Blind Independent Reasoning，再抽取 Consensus / Conflict / Unique Insight，并基于证据裁决。

技术语言 Adaptive Long-Horizon Multi-Model Agent Runtime

核心不是「支持很多模型」，而是 WinWinCode 决定：什么时候不需要模型、什么时候用 Jev、什么时候用单模型、什么时候召集整个 Fusion Council。

最终目标：不是寻找一个永远最强的模型，而是建立一个比任何单模型更会使用模型的 Runtime。

Fusion Epic 最终 DoD（非第一批）

  • Blind Independent Panel
  • Consensus / Conflict / Unique 分析
  • Evidence-based adjudication
  • Partial provider failure 可恢复
  • Intelligence Router
  • Risk-aware escalation
  • Jev integration
  • Memory integration
  • Thread bootstrap review
  • Provider-aware cost policy
  • Fusion 全链路可审计
  • Fusion benchmark 优于 single-model baseline
  • 不因 Fusion 引入新的 Canonical State 写权
