# 架构决定

ADR 记录长期有效的架构选择、原因和实施边界。ADR 的接受状态不代表代码迁移已经完成。

| 编号 | 决定 | 实施状态 |
| --- | --- | --- |
| [0001](0001-source-code-comments.md) | 第一方源码的说明写入文档 | 保留 SPDX 头；其他注释清理与检查待实施 |
| [0002](0002-react-ui.md) | 前端统一使用 React | 当前仍包含命令式 DOM 页面 |
| [0003](0003-single-product.md) | 单一产品与内部模块 | 模块和发布配置清理待实施 |
| [0004](0004-scope-model.md) | 单用户、单工作区、多项目 | 当前协议仍使用四级作用域 |

创建新 ADR 时使用 [模板](template.md)。编号连续递增。记录状态、决定、源码依据、影响和验收条件。

修改已接受的决定时，保留原决定的记录，并通过新的 ADR 说明替代关系。普通事实修正可以直接修改相关实现文档。
