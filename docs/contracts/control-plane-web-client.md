# Control Plane Web Client 实现合同

机器规则位于
[`control-plane-web-client.rules.json`](./control-plane-web-client.rules.json)。当前状态是
`implemented-enforced`：`apps/client`、生成 DTO、HTTP/WebSocket facade 和 Rust Server
边界已经按同一份 canonical schema 接通，门禁检查实际文件、结构和行为。

## 单一路径

```text
apps/client
  └─ control-plane-client.ts
       └─ generated/control-plane-client.ts + generated/contracts.ts
            └─ Rust winwincode-server
                 └─ winwincode-control-plane
                      └─ winwincode-worker
```

`apps/client` 是唯一浏览器应用。`winwincode-server` 是唯一公开 HTTP/WebSocket 边界；
`winwincode-control-plane` 是 ProductSession、Delivery、策略、凭据引用、调度和 receipt
的业务事实所有者；`winwincode-worker` 只持有 Job、Lease、fencing、工作区和执行运行时。
`winwincode-local` 负责本地组装，`crates/helper` 只提供经过身份校验的辅助可执行文件。
Web 不直接连接 Worker；页面只显示投影，也不保存业务事实。

## 生成输出

生成器的输入固定为：

- `schema/winwincode/v1/domain.schema.json`；
- `schema/winwincode/v1/control-plane-http.schema.json`；
- `schema/winwincode/v1/control-plane-events.schema.json`。

输出固定为：

- `apps/client/src/generated/contracts.ts`：canonical DTO；
- `apps/client/src/generated/control-plane-client.ts`：HTTP、WebSocket、StrongFlow 和
  ProductSession runtime projection client。

生成文件带有 `Generated by scripts/generate-contracts.mjs. Do not edit.` 标记。手写页面
只能导入 `apps/client/src/control-plane-client.ts` 或同目录类型 facade；页面不手写 wire
DTO、路径、事件 frame 或 Worker 地址。

## HTTP 合同

首次加载通过唯一 facade 的 `GET /api/v1/auth/session` 恢复 secret-free Actor、Scope 和
过期时间；登录 `POST` 和登出 `DELETE` 也经过同一 facade。写操作只向
`POST /api/v1/commands` 发送 generated `CommandRequest`，读操作只向
`POST /api/v1/queries` 发送 generated `QueryRequest`。

每个 command 原样保留调用方的 `requestId` 和 `expectedRevision`。网络重试必须重发相同
envelope 和 request ID，不能暗中改变 revision。query cursor 是绑定 Scope、查询、筛选条件
和快照的 opaque 值，页面不能拆解或跨查询复用。

请求发出前和响应返回后都执行 canonical schema 校验；请求名、结果分支或必需字段不一致时
产生有界 `INVALID_RESPONSE`。非成功响应只转换为 `ErrorEnvelope`。公开错误仅有
`code`、`message`、`requestId`、`retryable` 和清理后的 `details`，不复制 body、header、URL、
stack、Authorization、Credential、Token 或 Provider 请求/响应。

## WebSocket 合同

事件连接由 generated client 建立，路径为 `/api/v1/events`。Client 只发送四种 frame：
`transport.subscribe.v1`、`transport.resume.v1`、`transport.ack.v1` 和
`transport.pong.v1`；业务 command 仍走 HTTP。

事件 handler 成功后才推进 cursor 并发送累计 ack。普通断线和背压关闭从最后确认的 cursor
续传；权限撤销清空订阅并停止自动重试；事件用完整 `eventId + sequence + payload` 去重，
重复 ID 对应不同 payload 或序号断档都结束连接。订阅 accepted 返回的 baseline 后，第一条
事件必须是 baseline sequence 加一。

Delivery runtime projection reset 先成对读取 `delivery.get` 和 `runtime.projection.get`，
两个响应及其 cursor 都属于同一 Scope、Delivery 和 revision 后才替换页面快照。任一读取
失败就丢弃这次部分结果并保持空快照；不能先订阅，也不能把一半新结果和一半旧结果拼接。
ProductSession runtime projection reset 只读取 `runtime.projection.get`，不附带 Delivery、
StageRun 或其他页面身份。

## 页面和错误边界

`apps/client/src/generated` 之外不得调用浏览器网络 API，不得声明 command/query/event
wire literal，也不得导入 Server、Control Plane、Worker 或 ExecutionPort 的 Rust/运行时
模块。页面只处理 typed projection 和 `ControlPlaneClientError`。

`ControlPlaneClientError` 只公开稳定分类、canonical code、请求 ID、是否可重试和清理后的
details。旧 generation 的异步 handler 完成后不得恢复新的 cursor、ack 或页面快照；登出、
关闭、权限撤销和 reset 都推进 subscription generation。
