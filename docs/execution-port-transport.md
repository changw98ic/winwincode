# 远程执行通道边界

Execution Port v1 保留整数数组形式的帧字段。内层帧上限为 256 KiB，请求正文上限为 1088 KiB，应答正文上限为 2 MiB。构造、编码和解码均检查实际编码尺寸；应答分页同时受 128 条和正文尺寸约束，剩余消息继续留在原队列。

新候选按最多 64 KiB 原始数据分块，并根据完整帧中的租约、身份和编码开销缩减预算。首次保留前验证全部帧的线上编解码；不可变内容与分块索引独立保存，ACK 只更新小记录。重启时验证完整内容，发送资格检查只读取当前分块。

升级时，旧 JSON 记录迁移为内容 BLOB、分块索引和小记录，保留原来的消息身份、序号与 ACK 游标。已经发送的旧分块计划不能原地改变：超限的旧帧报告永久尺寸错误，须通过正常取消及 fencing 恢复到新 attempt 后重新生成候选。迁移不会把同一消息身份替换成不同内容。

| Worker 错误码 | 含义 | 行为 |
| --- | --- | --- |
| `REMOTE_WORKER_TRANSPORT_UNAVAILABLE` | 连接中断、超时、408、429 或 Server 5xx | 保留消息，按现有退避重试 |
| `REMOTE_WORKER_AUTHENTICATION_REJECTED` | 401、403 或不可用的认证令牌 | 当前进程结束，由 Device 处理退出及重新授权 |
| `REMOTE_WORKER_PROTOCOL_INVALID` | 永久协议错误、错误方向或其他拒绝状态 | 当前进程结束，保留诊断类别 |
| `REMOTE_WORKER_MESSAGE_TOO_LARGE` | 最终编码超限或 HTTP 413 | 当前进程结束，保留尺寸错误类别 |

只有认证拒绝设置认证失效状态。HTTP 客户端使用标准解析器，支持定长、chunked 和连接结束形式；状态分类先于正文读取，读取后的正文仍受 2 MiB 上限约束。

Server 应答配额按 Worker/instance 隔离。接收业务消息前先处理 ACK 并检查应答空间；只有权威确认撤销的身份和已被新实例取代的身份才退休残留应答。活跃控制消息继续等待确认。
