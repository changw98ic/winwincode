# WinWinCode 0.1.0-alpha.2

`0.1.0-alpha.2` 打通了浏览器 Web、Backend、Device Client、本地 Worker 与内嵌 Codex Core 的 Community 远程执行链路。

## 主要变化

- Web 可以生成连接码，Device Client 使用连接码加入并持续领取任务。
- `wwc device serve/status/restart/logs` 提供 macOS launchd 与 Linux systemd user service 所需的正式入口。
- Device Client 使用 HTTPS 连接 Backend，并把任务交给绑定仓库中的本地 Worker 执行。
- Community Compose 提供独立的 Web 与 remote-only Backend，数据、仓库和模型凭据分别持久化。
- WorkItem、WorkRun、Candidate、Evidence 与最终判定使用当前单一路径。

## 验证范围

- Web API → Backend → Device Client → Worker → Codex Core 的真实模型任务已完成并生成候选。
- 源码格式、TypeScript、Rust、产品构建、完整测试和 direct API 门禁必须绑定同一提交通过。
- 四个受支持平台的 Server、Worker、Kernel helper、Device Client 与 Web 文件必须由发布矩阵原生构建并验证签名、摘要和平台身份。

Control Plane 使用 `winwincode/v1`，Worker 通信使用 ExecutionPort v1，Delivery 数据结构版本为 3。发布产物绑定同一源码提交和该提交的 `SOURCE_DATE_EPOCH`。

## 支持平台

- `aarch64-apple-darwin`
- `x86_64-apple-darwin`
- `aarch64-unknown-linux-gnu`
- `x86_64-unknown-linux-gnu`

## 当前限制

这是 Community 单 Owner 的 alpha 预览版。真实任务需要用户自行配置模型 Provider 凭据；Windows 不在本次支持范围内。
